# Paradise Nursery Shopping Application

**Project Name:** Paradise Nursery — Online Plant Shop

## Overview
Paradise Nursery is a dynamic, responsive React and Redux Toolkit web application for an online houseplant store. Users can explore a curated catalog of houseplants organized by category, add items to a live shopping cart, adjust quantities, and view real-time subtotal and total cost calculations.

## Features
- **Landing Page:** Welcoming hero section with company overview and quick navigation to the plant catalog.
- **Categorized Plant Catalog:** 18 unique plants across 3 categories (*Air Purifying Plants*, *Aromatic Fragrant Plants*, and *Low Maintenance Plants*) with thumbnails, descriptions, pricing, and dynamic "Add to Cart" button states.
- **Persistent Navigation Bar:** Quick navigation between Home, Plants, and Cart with a live item counter badge.
- **Interactive Shopping Cart:** Real-time unit totals, overall cart total, quantity increment/decrement controls, item removal, and checkout notification.
